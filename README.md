# MojeRepo

Projekt został utworzony w celu nauki systemu kontroli wersji Git oraz platformy GitHub.

## Funkcjonalności
- tworzenie repozytorium
- dodawanie plików
- tworzenie branchy
- pull request
- issues
- współpraca wielu użytkowników

## Jak uruchomić projekt
1. Sklonuj repozytorium:
   git clone https://github.com/JacekJochemczyk/MojeRepo.git

2. Otwórz folder projektu.

3. Edytuj pliki według potrzeb.
